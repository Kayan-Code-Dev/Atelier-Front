# Contract template (fields 1–25)

Every Tool Contract uses this schema:

1 Tool Name · 2 Business Purpose · 3 Description · 4 Business Intent(s) · 5 Required Capabilities · 6 Required Permissions · 7 Allowed Operating Modes · 8 Required Context · 9 Expected Inputs · 10 Expected Output · 11 Possible Outcomes · 12 Failure Scenarios · 13 Validation Rules · 14 Approval Requirements · 15 Human Escalation Rules · 16 Audit Events · 17 Analytics Events · 18 Business Rules · 19 Security Considerations · 20 Idempotency Rules · 21 Concurrency Considerations · 22 Side Effects · 23 Dependencies · 24 Related Tools · 25 Versioning Notes

Modes shorthand: **A**=Assistant · **H**=Hybrid · **F**=Full Auto.  
“Permissions” = capability keys enforced by Permission Engine (same vocabulary as Use Cases).

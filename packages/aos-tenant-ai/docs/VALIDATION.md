# Validation Scenarios

Covered by PHPUnit:

1. Tenant missing/empty  
2. Workspace missing  
3. Conversation missing  
4. User without permission  
5. Tool unavailable in subscription  
6. Cross-tenant access  
7. Conversation not owned by tenant  
8. Integration not enabled  

Plus happy paths: workspace ensure, multi-conversation, messages, context, session, memory, dashboard menu.
